OpenDown - getting started
==========================

Files
-----
  opendown.exe                 the download manager (GUI + CLI)
  extension\                   browser extension files (crx + unpacked folder)
  uninstall.exe                uninstaller

Command line
------------
  opendown.exe --cli <URL> [-o DIR] [-f NAME] [-n CONNS] [--limit KB] [--resume]

Data & ports
------------
  %APPDATA%\OpenDown\          config.json + tasks.json
  Grabber endpoint:            http://127.0.0.1:10081   (POST /add, GET /ping)

Browser extension
-----------------
Browsers now block extensions that are installed outside their official stores
(2024+ security policies), so the extension has to be enabled once, manually:

  1. Open  edge://extensions   (or  chrome://extensions )
  2. Turn ON "Developer mode"
  3. Click "Load unpacked" and select this folder:
       extension\unpacked
     (extension\browser-extension-setup.cmd opens everything for you and puts
      the folder path in your clipboard)
  4. Keep "Developer mode" ON while using the extension.

Notes
-----
  * The extension stays enabled while Developer mode is on. The "developer mode
    extensions" warning shown by the browser at startup is normal and harmless.
  * Firefox is not supported (.crx / unpacked is a Chromium format).
  * The extension talks to the app over localhost only - no data leaves your PC.
  * Close or minimize hides OpenDown to the system tray - downloads keep running.
    Right-click the tray icon for Show / Exit. "Start with Windows" toggle lives in
    Options -> System.
  * opendown.exe is unsigned: Windows SmartScreen may warn on first run
    (click "More info" -> "Run anyway").
  * Uninstall via Windows Settings -> Apps, or uninstall.exe in this folder.
